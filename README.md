# ⚔ Свой Манчкин Онлайн

Онлайн-версия манчкина для компании друзей: свои карты, локальные приколы,
комнаты по ссылке. Логика правил — на сервере, в браузере — стол и карты.

## Запуск

```bash
npm install   # один раз
npm start     # сервер на http://localhost:3000
```

- Создатель комнаты жмёт «Создать комнату» и кидает друзьям ссылку
  (`http://<твой-IP>:3000/?room=КОД`) — друзья из твоей Wi-Fi сети заходят по ней.
- Для игры через интернет: пробрось порт 3000 или подними туннель
  (`cloudflared tunnel --url http://localhost:3000`, ngrok и т.п.) — получишь
  публичную ссылку.
- Отключился — просто войди в комнату под тем же именем: игра вернёт тебя на место.

## Структура

| Файл | Что это |
|---|---|
| `game/cards.js` | **Все карты. Мы правим его вместе** — монстры, шмот, проклятия, классы |
| `game/engine.js` | Правила: фазы хода, бой, побег, уровни, классы |
| `game/rooms.js` | Комнаты и коды |
| `server.js` | HTTP + WebSocket |
| `public/` | Интерфейс: лобби, стол, рука, чат |

## Что реализовано

- Уровни 1–10, победа — 10-й уровень через убийство монстра (карты уровней качают только до 9)
- Ход: «открыть дверь» → бой/проклятие/хабар → благотворительность (сброс до 5 карт)
- Бой: сила (уровень + шмот + разовые карты) против силы монстра, помощь друга
  (помощник получает 1 сокровище при победе), усиление монстра другими игроками
- Побег: 5+ на кубике, шмот даёт бонус к побегу, при провале — дурные последствия
- Шмот: голова/тело/ноги + 2 руки, крупное — не больше одного, продажа хлама
  на 1000 золота = +1 уровень
- Классы: **Воин** (побеждает при равенстве, сброс карт = −1 монстру),
  **Маг** (раз за бой телепорт-побег), **Вор** (раз за игру крадёт шмотку),
  **Клирик** (+3 против нежити, раз за игру +1 уровень)
- Проклятия из руки на любого игрока, «слухи» (+5 следующему монстру), смерть
  от дракона: уровень 1, шмот в сброс, добор 4 дверей

## Деплой на Render.com

1. Залей проект в GitHub-репозиторий.
2. На [dashboard.render.com](https://dashboard.render.com): **New → Blueprint** — Render найдёт `render.yaml` сам.
3. Всё. Ссылка вида `https://munchkin-company.onrender.com` — кидай друзьям, WebSockets работают из коробки.

Нюансы бесплатного плана: сервер засыпает без трафика (первый заход просыпается ~30 сек),
комнаты живут в памяти — при перезапуске сервера партии сбрасываются.
